# ScholarsMate 🎓

ScholarsMate is an academic RAG assistant designed for source-locked literature synthesis, page-level citation mapping, and active learning.

## Features
- Layout-aware PDF ingestion and chunking
- Local vector persistence (ChromaDB)
- Source-locked prompting to eliminate hallucinations
- Automated literature matrix generation

## Tech Stack
- **Backend:** Python, FastAPI, PyMuPDF, ChromaDB, SQLite
- **Frontend:** Next.js, React, Tailwind CSS
